  Startup sequence:
    1. Load topology JSON → TopologyEngine + DeviceManager
    2. Generate SNMP datasets → datasets/snmp/*.snmprec
    3. Generate gNMI datasets → datasets/gnmi/*.gnmi.json
    4. Bind virtual IPs on loopback (Linux ip alias)
    5. Start SNMPSim subprocess (pointing at datasets/snmp/)
    6. Start gNMI gRPC server (gnmi_server.py)
    7. Start sFlow controller (sflow_controller.py)
    8. Start DeviceStateStore ticker
    9. Register DeviceStateStore rule engine callback → dcim_bridge.send_alert()
    10. Start dcim_bridge background thread (polls metrics every TICK_INTERVAL)
    11. Start http_api FastAPI server (fault injection endpoint)
    12. Register all agents with DCIM Server
    13. Block forever (asyncio event loop)

  ── dcim_bridge.py ───────────────────────────────────────────────────────────

  class DCIMBridge:
    def __init__(self, dcim_url, device_manager, state_store, network_id):
      self.dcim_url = dcim_url        # http://dcim-server-a:8080/api/v1
      self.session = httpx.AsyncClient()

    async def register_all_agents(self):
      # Send POST /register for each server device in topology
      # DeviceType.SERVER → registered as DCIM agent
      # agent_id = f"{network_id}-{device.name}"
      # hostname = device.name, ip_address = device.ip_address

    async def sync_metrics_loop(self, interval=30):
      # Every interval seconds:
      while True:
        await asyncio.sleep(interval)
        await self._send_all_metrics()

    async def _send_all_metrics(self):
      for device in device_manager.get_all_devices():
        metrics = state_store.get_metrics(device.ip_address)
        payload = {
          "agent_id": f"{network_id}-{device.name}",
          "timestamp": datetime.utcnow().isoformat(),
          "metrics": [
            {"type": "cpu_usage",         "value": metrics["cpu_usage"],      "unit": "%"},
            {"type": "memory_usage",      "value": metrics["memory_pct"],     "unit": "%"},
            {"type": "disk_usage",        "value": metrics["disk_pct"],       "unit": "%"},
            {"type": "temperature",       "value": metrics["cpu_temp"],       "unit": "C"},
            {"type": "power_consumption", "value": metrics["power_draw_w"],   "unit": "W"},
            {"type": "network_rx",        "value": metrics["net_rx_mbps"],    "unit": "Mbps"},
            {"type": "network_tx",        "value": metrics["net_tx_mbps"],    "unit": "Mbps"},
            # environmental (for sensors only):
            {"type": "humidity",          "value": metrics.get("humidity"),   "unit": "%"},
            {"type": "dewpoint",          "value": metrics.get("dewpoint"),   "unit": "C"},
            {"type": "airflow",           "value": metrics.get("airflow"),    "unit": "m/s"},
          ]
        }
        await self.session.post(f"{self.dcim_url}/metrics", json=payload,
                                headers={"X-Agent-ID": payload["agent_id"]})

      # SNMP device metrics (switches, routers) → DCIM snmp-metrics endpoint
      for device in device_manager.get_devices_by_type(DeviceType.SWITCH):
        snmp_payload = { "agent_id": ..., "snmp_metrics": [...] }
        await self.session.post(f"{self.dcim_url}/snmp-metrics", json=snmp_payload, ...)

    def on_rule_fired(self, trap_action):
      # Called by rule engine when a condition triggers
      # Maps TrapAction → DCIM alert payload
      severity_map = {
        "critical": "critical", "major": "warning",
        "minor": "info", "informational": "info"
      }
      alert = {
        "agent_id": f"{network_id}-{trap_action.device_id}",
        "type": trap_action.trap_type,
        "severity": severity_map[trap_action.severity],
        "message": trap_action.message,
        "metric": trap_action.metric_name,
        "value": trap_action.metric_value,
        "threshold": trap_action.threshold
      }
      asyncio.run_coroutine_threadsafe(
        self.session.post(f"{self.dcim_url}/alerts", json={"alerts": [alert], ...}),
        self.loop
      )

  ── http_api.py ──────────────────────────────────────────────────────────────

  FastAPI app exposing per-container control:

  GET  /status          → network_id, device_count, tick_count, active_faults

  POST /fault           → inject fault
    body: {
      "type": "cpu_spike" | "memory_leak" | "disk_full" | "temp_critical"
           | "link_down" | "link_flap" | "bgp_down" | "ups_on_battery"
           | "agent_offline" | "rack_failure" | "humidity_alert" | "airflow_alert",
      "target": "device_name OR rack_id OR 'all'",
      "duration_seconds": 120,
      "intensity": 0.9       (0.0-1.0 scale)
    }
    → Calls DeviceStateStore to override metric values temporarily
    → Or stops dcim_bridge sync (agent_offline)
    → Or calls tc netem for packet_loss/link_latency

  DELETE /fault         → clear all active faults → restore normal metrics

  POST /profile         → change telemetry profile
    body: { "profile": "normal" | "high_load" | "maintenance" | "idle" | "overnight" }
    → Adjusts DeviceStateStore base values

  POST /speed           → change simulation speed
    body: { "multiplier": 10 }
    → Adjusts tick_interval (e.g., 10x = tick every 3s instead of 30s,
       metric changes appear 10x faster)

  POST /topology/reload → reload topology JSON from disk

  GET  /devices         → list all devices with current metrics

  GET  /devices/{name}  → single device metrics

  POST /trap            → manually send trap
    body: { "device": "device_name", "trap_type": "LINK_DOWN", "interface": 2 }

  class LinuxIPAliasManager:
    # Replaces Windows netsh with Linux ip command
    def bind_ip(self, ip: str, interface="lo"):
      subprocess.run(["ip", "addr", "add", f"{ip}/32", "dev", interface])

    def unbind_ip(self, ip: str, interface="lo"):
      subprocess.run(["ip", "addr", "del", f"{ip}/32", "dev", interface])

    def bind_all(self, devices: list[Device]):
      for device in devices:
        self.bind_ip(device.ip_address)
        if device.mgmt_ip:
          self.bind_ip(device.mgmt_ip)

    def cleanup(self):
      # Called on SIGTERM — removes all bound IPs
      for ip in self._bound:
        self.unbind_ip(ip)

  11. TELEMETRY OUTPUT TO DCIM (what dcim_bridge.py sends)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Every tick for each device → POST /api/v1/metrics

  FROM DEVICE STATE STORE              → DCIM METRIC TYPE
  ─────────────────────────────────────────────────────────
  device.cpu_usage (%)                 → "cpu_usage"
  device.memory_used/total (%)         → "memory_usage"
  device.disk_used/total (%)           → "disk_usage"
  device.cpu_temp (°C)                 → "temperature"
  device.inlet_temp (°C)               → "inlet_temperature"
  device.power_draw_w (W)              → "power_consumption"
  iface.in_octets / tick_interval      → "network_rx" (converted to Mbps)
  iface.out_octets / tick_interval     → "network_tx" (converted to Mbps)
  device.sys_uptime (centiseconds)     → "uptime" (converted to seconds)

  Sensor devices only:
  device.humidity (%)                  → "humidity"
  device.dewpoint (°C)                 → "dewpoint"
  device.airflow (m/s)                 → "airflow"

  → POST /api/v1/snmp-metrics (switches, routers)

  iface.in_octets, out_octets          → ifInOctets, ifOutOctets
  iface.in_errors, out_errors          → ifInErrors, ifOutErrors
  iface.oper_status                    → ifOperStatus
  device.sys_uptime                    → sysUpTime

  → POST /api/v1/alerts (when rule fires via trap_engine callback)

  Rule → Trap Type → DCIM Alert Severity:
  cpu_usage > 90%  → CPU_HIGH trap      → critical alert
  memory > 85%     → MEMORY_HIGH trap   → warning alert
  oper_status 1→2  → LINK_DOWN trap     → warning alert
  LinkDown 3×/60s  → LINK_FLAP trap     → critical alert
  cpu_temp > 60°C  → TEMP_ALERT trap    → critical alert
  BGP established→idle → BGP_DOWN      → critical alert
  ups_status=on_battery → UPS_ON_BATT  → critical alert
  ups_status=low_battery → UPS_LOW_BAT → critical alert
  ≥3 devices same rack  → RACK_FAILURE → critical alert
  humidity > 80%   → HUMIDITY_ALERT    → warning alert
  airflow < 0.5m/s → AIRFLOW_ALERT    → warning alert
